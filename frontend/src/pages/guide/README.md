# Guide de jeu — par jeu

À implémenter (Phase 5 du plan). Contrairement à la notice (règles brutes),
le guide de jeu est un tutoriel interactif jouable qui montre concrètement
comment jouer (ex: tirer un rayon, lire une couleur de sortie, remplir sa
feuille de solution) sur un mini-plateau d'exemple.
